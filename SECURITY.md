# Security Policy

## Supported Versions

Security updates are actively maintained for the latest release series of A1 Swaara.

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | Yes                |
| < 1.0.0 | No                 |

---

## Reporting a Vulnerability

The A1 Swaara team and maintainers take the security of our application and user data seriously. If you discover a security vulnerability or sensitive information exposure, please report it responsibly.

### How to Report
* **Private Disclosure**: Please send an email directly to **gowdavarshan466@gmail.com** or open a private security advisory on GitHub.
* **Do Not File Public Issues**: Please avoid filing public GitHub issues for sensitive security vulnerabilities until they have been reviewed and addressed.

### What to Include in Your Report
1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof of concept to reproduce the issue.
3. Relevant device architecture, Android OS version, and application build version.
4. Proposed remediation or fix, if available.

### Response Timeline
* We will acknowledge receipt of your report within 48 hours.
* We will provide a status update or proposed resolution within 7 days.
* Security fixes will be released as high-priority hotfix updates.
